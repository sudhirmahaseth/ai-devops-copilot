# AI DevOps Copilot 🤖

An AI-powered DevOps assistant built with **FastAPI**, **LangChain**, and **Streamlit** designed for automated log analysis, root cause diagnosis, and instant infrastructure remediation workflows.

## 🚀 Features
- **Automated Root Cause Diagnosis:** Instantly identifies structural bugs, database failures, or OOM issues from raw runtime logs.
- **Structured AI Insights:** Leverages Pydantic output formatting to deliver crisp severity assessments and structured response protocols.
- **Actionable Remediation Scripts:** Generates context-aware shell, Docker, or `kubectl` commands to quickly lower MTTR (Mean Time to Resolution).

## 🛠️ Tech Stack
- **Frontend UI:** Streamlit
- **AI Orchestration:** LangChain / LangGraph Agentic Workflows
- **Core LLM:** OpenAI GPT-4o-mini API
- **Deployment:** Docker & Streamlit Cloud
